# 新品质量门上线海报改稿示例

本例配合[定稿](reference.png)查看。新项目使用本次提供的发布主体、文案与日期。

## 改字的范围

用户要求“新品质量门管理改为新品质量门管控，质量门改为决策”时，通过用户标出的三个卡片确定替换范围。

| 位置 | 定稿文字 |
| --- | --- |
| 主标题 | 新品质量门 / 在线管控系统 |
| 状态与栏目 | 正式上线 / 新品质量门管控 |
| QG1 | 样机试制决策 |
| QG2 | 小批试产决策 |
| QG3 | 定型上市决策 |

| 序号 | 短标题 | 说明 |
| --- | --- | --- |
| 1 | 线上化 | 评审审批线上流转，过程记录全程留痕 |
| 2 | 标准化 | 管控标准强制卡点，不达标不得转阶段 |
| 3 | 可视化 | 实时查看质量指标，异常一键下钻 |
| 4 | AI智能审查 | 智能核查交付质量，自动提示改进 |

2026 年上线安排依次为 11.20 集团培训、11.30 模板适配完成、12.01 正式启用。

## 两种局部改法

- “流程改成小旗子”时，将决策模块切为阶梯，沿同一条线依次标出 QG1、QG2、QG3。三项决策沿用上表文字，最后检查编号与名称的对应。
- “这里也往下挪”时，根据截图选择决策组或下方升级区。先整体平移对应模块，再打开全图查看与上一栏、下一栏的距离。
