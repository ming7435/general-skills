# 成图验收清单

在原尺寸查看导出的 PNG，再缩到约 375 像素宽。使用本次定稿核对，发现问题时回到工作副本修改后重新导出。

| 核对项 | 通过条件 |
| --- | --- |
| 版本与范围 | 完整图对应用户指定的版本；改字或移动落在标注的模块。标注箭头、圈线和聊天窗口边缘未进入成图。 |
| 文字与数据 | 系统名、栏目名、编号、决策名、署名和日期逐项对应定稿。本次没有提供的数值或日期没有从样稿带入。 |
| 流程 | 卡片版每张卡片的编号与名称对应；小旗版沿连续轨道从左至右依次读出相同的节点。 |
| 布局与可读性 | 原尺寸下无溢出、缺字、缺图或裁边。手机宽度下能读出主标题与节点。移动后栏标题与本栏内容靠近，上下两栏之间有清楚的间隔。 |
| 交付文件 | 打开交付文件能看到整张海报。若附可编辑母版，在交付目录中打开 HTML 后，背景和标识仍能加载。 |

## 质量门案例的验收样例

- 收到“改为决策”的标注时，整图同时出现系统名“新品质量门在线管控系统”、栏目“新品质量门管控”和三个分别以“决策”结尾的节点。逐项对照[定稿文案](../examples/system/revision.md)。
- “小旗版再往下挪”时，只检查修改坐标不够。打开整张图，沿三个旗杆找到各自的台阶，确认最后一项与下一栏标题之间仍有留白。
- 检查导出链路时，可在副本中移走背景后尝试导出。缺图应产生可识别的错误；恢复背景后再打开 PNG 复核。已有同名成图时，另取文件名可保留上一版。
