# 系统风格

[完整样稿](../examples/system/reference.png)为 941 × 1672 的竖版发布海报。先看系统名称和“正式上线”，再看决策节点、升级说明和启用日期。

## 色彩与层级

- 深夜蓝铺底，城市与光环集中在底部。正文区保留暗底，用白字和浅青色小字压住背景。青蓝光用于切角边框、轨道和状态栏。
- 系统名称居中分两行，以最粗的白色微斜字为主视觉。示例左上用红色三一标识、右上署名“研发管理总部”。换发布方时同步替换标识、替代文本和署名；没有标识素材时可采用文字署名。
- 四项升级按从左到右、从上到下阅读。每项用一个短标题配一至两行说明。日期按实际发生顺序排列，说明贴近对应日期。

## 修改母版

复制 [assets/system](../assets/system/) 整个目录。用浏览器打开副本中的 [layout.html](../assets/system/layout.html)。[背景](../assets/system/background.png)和[品牌图](../assets/system/sany-mark.png)与 HTML 保持同目录。母版用于复用层级和编辑文字；需要精确复现指定成图时从那张原图或对应源稿修改。

| 修改意图 | 母版位置 | 核对内容 |
| --- | --- | --- |
| 对比三个决策点 | `.gate-group` 的 `data-flow="cards"` | 三个编号与决策名称一一对应 |
| 展示流程先后 | 改为 `data-flow="flags"` | 同一组节点从左下向右上依次出现，小旗与阶梯相接 |
| 下移决策组 | 在 `#poster` 调整 `--gate-offset` | 标题、卡片或小旗、连线一起移动 |
| 下移升级区和排期 | 调整 `--lower-offset` | 两区整体下移，最后一行与城市光环之间仍有空隙 |
| 单独移动其中一栏 | 调整该栏自身的 `top` | 检查与上下两栏的间距 |

以样稿尺寸为准，状态框底部约在 y=485，决策标题约在 y=542，卡片从 y=609 起排，轨道约在 y=785。升级标题约在 y=855，排期标题约在 y=1280。局部移动可先试 30 像素，再看整张图决定间距。

卡片和小旗母版均按三个节点设计。节点数变化时同时重排节点及对应轨道，按实际内容调整上下留白。
