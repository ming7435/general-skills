# 蓝金工程车队邀请函

用于带正式称谓、邀请正文、落款和会务信息的中文邀请函。用户提到“蓝金车队”“上次工程车队那版”时选用。先看[整张样稿](../examples/blue-gold-fleet/reference.jpg)，再复制[可编辑母版](../assets/blue-gold-fleet/layout.html)及[同目录背景](../assets/blue-gold-fleet/background.jpg)。样稿的活动与会务信息均为虚构示例。

## 版式

以 1130 × 1598 像素竖版设计，导出高清图时等比放大。以整张邀请函为参照确定宽高，局部截图只用于定位。底色由藏蓝向宝蓝过渡，左上金色微光与右下金色弧光呼应；正文下方保留宽阔的车队和地面反射。

| 区域 | 排版与制作 |
| --- | --- |
| 页首 | 左上放本次提供或获准使用的品牌标识，保留比例；右上放活动系列或主办方。无品牌要求时可沿用纯文字活动标识。 |
| 标题 | 顶部居中先排细衬线大写 INVITATION，再排金色宋体“邀请函”。短金线下放一至两行活动主题。 |
| 邀请正文 | 以约 99 px 左右页边距排版。称谓用暖金色宋体半粗 31 px。问候语“您好！”和段落同用正文字体、26 px；段首缩进两字，段间留白。 |
| 落款 | 右边缘与正文右边缘对齐；一个署名主体独占一行，下排发函日期，两行右对齐、同色。按用户确认的单一部门名署名，如“研发管理总部”。 |
| 活动信息 | 两道细线之间按标签和值排两列。“时间、地点、着装、联系”的字号、字重和金色与称谓一致。值与落款同用常规黑体、约 24 px、浅米金色 #FAE9CD。仅列本次活动提供的字段。 |
| 车队和页脚 | 车辆在底部横向排成浅弧，近处略大，保留车轮落地感和倒影。用户提供的页脚文案在光带下居中排一行金字，与车辆留开距离。 |

样稿沿用八台设备的定稿顺序，从左至右为白色搅拌车、蓝色工程卡车、黄色履带挖掘机、白色牵引车、浅蓝自卸车、黄色压路机、白色搅拌车、浅蓝牵引车。改文字可直接复用底图。用户要求更换或挪动车型时，按用户给定的产品图和顺序重排，检查尺寸、透视、遮挡、落地阴影与前后层次。

## 改稿与验收

- 先填本次称谓、问候、正文、落款、会务信息及页脚。样稿里的日期、地点和联络方式仅用于演示。
- 在手机宽度和原尺寸各看一次。留意正文结尾与落款是否重叠，右侧长联系方式是否出界，最后一辆车与页脚是否完整。长文可先调整换行和段距，需要删改定稿文案时向用户核实。
- 要求图片时交付整张 PNG。用户要求可编辑 PPT 时，在工具支持的情况下保留同一画幅，将正文、主题、落款、会务信息做成可编辑文字，导出后核对文字和车队位置。
