# 海报风格库

按用户指定的样稿、定稿文字和发布场景，制作能直接在手机上查看的中文海报。要改已有设计时，从用户指认的版本开始。

## 任务与输入

| 用户意图 | 使用哪些输入 | 关键资料缺失时 |
| --- | --- | --- |
| 制作一张海报 | 本次主题、要传达的信息、指定风格；有署名、排期或品牌要求时使用本次资料 | 用已有信息起稿。发布日期尚未确定时可以省略日期栏，需要印出具体日期时再询问。 |
| 修改指定位置 | 用户选中的底稿、修改位置与目标。可编辑源稿和标注截图均可辅助定位 | 先查找本次已提供的完整图。只有局部截图且需要精确交付整图时，请用户补完整底稿，可先核对局部文案。 |
| 收录一种风格 | 用户指定的样稿及收录意图，优先采用用户给定的名称 | 只有局部且无法辨认整体版式时，先取得完整样稿。仅作为本轮背景参考的图片用于本次设计。 |

素材分散在多条消息或多个附件时，可用[海报需求收集表](assets/templates/task-intake.md)按栏目整理，已有答案直接填入。

## 选风格与制作

| 已收录风格 | 识别方式 | 资源 |
| --- | --- | --- |
| 系统风格（蓝色上线海报） | 深蓝城市光幕、青蓝切角框、白色粗斜大标题，常用于系统启用和功能升级。 | [完整样稿](examples/system/reference.png) · [制作说明](references/system.md) · [可编辑母版](assets/system/layout.html) |
| 蓝金工程车队邀请函 | 藏蓝金色竖版、双语标题、正式信函和底部工程车队。适用于“用上次蓝金车队那版做邀请函”等请求。 | [完整样稿](examples/blue-gold-fleet/reference.jpg) · [制作说明](references/blue-gold-fleet.md) · [可编辑母版](assets/blue-gold-fleet/layout.html) |

1. **制作。** 以用户点名或指认的风格为先。“我的系统风格”沿用蓝色上线海报；只有活动邀请文案且未指定风格时可选蓝金车队。先看对应样稿与说明，复制母版和同目录素材，按本次资料替换文案、品牌和日期。
2. **改稿。** 系统海报按[质量门改稿示例](examples/system/revision.md)处理栏目、流程和节点。邀请函按[蓝金车队制作说明](references/blue-gold-fleet.md)处理问候语、正文、部门署名、会务信息、车辆和页脚。局部标注以用户选中的完整底稿为准。
3. **收录与维护。** 用户明确说“这是新风格样稿”“以后按这个做”“收进风格库”，或要求调整以后都适用的制作规则时，在本次对话中更新现有技能。用户仅要求试排、改本张海报或表示满意时，继续完成当前海报。

## 在飞书对话中更新本技能

更新目标始终为当前智能体里的自定义技能 `poster-style-library`。例如，开发者发送一张定稿并说“这是新风格样稿，叫极简白”，即可发起一次收录。

1. 通过飞书提供的技能编辑能力，读取当前已安装版本的风格表和相关说明，以它为本次修改的基准。开发态支持有相应权限的开发者对话修改；运行态还需已开启「无感模式」。操作权限取决于飞书对当前身份的判定。[飞书技能使用说明](https://aily.feishu.cn/hc/1u7kleqg_nto2bybm)
2. **新增风格**时，按用户命名，把定稿图保存到本技能的 `examples/`，把配色、字体层级、布局和适用场景写入 `references/`，最后在风格表加入可读取的样稿及说明链接。对话附件或临时预览需要先取得可在下次调用时读取的持久副本。**更新已有风格**时，编辑对应条目；同名且样稿相同的重复请求复用该条目。如果同名但明显是另一套设计，只需澄清是替换还是另取名称。**修改长期规则**时，只改用户点明的风格说明或制作步骤。
3. 通过当前智能体的技能编辑功能保存这组变更，再从已保存的技能重新打开风格表、说明和新增样稿。规则变更则复读对应条款。提交超时或遇到版本冲突时，先重新读取现版，核对本轮变更是否已生效，再补缺项。核对成功后，回复风格名和一句下次可用的调用示例。
4. 当前对话缺少技能编辑权限时，给开发者一条可在开发态执行的修改请求。如果编辑器只能改文字、无法保存样稿，或只能写入临时工作区，说明哪部分尚未持久保存。有完整现版和打包能力时，可提供保留全部既有风格的替换 ZIP。向 GitHub 推送或把样稿发给其他人，按用户另外明确的请求处理。

## 输出与验收

用户说“给我海报”或“看效果”时，交付完整 PNG 并直接展示。对改稿，先按[成图验收清单](references/acceptance.md)和所选风格说明核对修改区域，再检查整张图。用户要求源稿时按指定格式交付；未指定格式时可附 HTML 与同目录素材。

图像编辑、浏览器截图和附件预览取决于当前环境；按[工具与导出说明](references/integration-status.md)选择可用方式。导出失败时保留可编辑副本，明确当前可交付的文件和仍缺的成图。
