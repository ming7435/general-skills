# 海报需求收集表

根据当前对话和附件整理，只填写影响本轮交付的项目。局部改字通常只需记录底稿和替换文字。

| 项目 | 记录内容 |
| --- | --- |
| 任务与交付 | 新作、局部修改或收录风格；完整 PNG、可编辑源稿或风格条目 |
| 视觉依据 | 选中的风格、完整底稿文件、局部标注对应的栏位 |
| 发布信息 | 系统海报记录本次发布主体、系统全称、发布状态和日期；邀请函记录活动主题、发函主体和已确定的会务信息 |
| 业务内容 | 系统海报按阅读顺序核对栏目、编号、节点与时间；邀请函核对称谓、问候、正文、落款、会务字段和页脚文案 |
| 要改的位置 | 记录“哪个栏位的原文 → 定稿文字”，或记录要一起移动的标题、卡片、徽标和轨道 |
| 验收依据 | 哪张图确定版本、哪条消息确定文案、手机预览要能读清哪些信息 |

例如，收到“把三个质量门改为决策”以及圈出三张卡片的截图，可记录“目标为 QG1 至 QG3 的卡片内文，主标题沿用选中底稿”。
