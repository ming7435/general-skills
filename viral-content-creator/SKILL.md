# 爆款内容创作（Viral Content Creator）

## 概述

把「爆款可以被拆解，方法论可以被学习，但内容必须 100% 原创」作为核心信念。先从对标作品里提炼可复用的钩子、结构、风格、节奏与策略，再用这些规律去包装用户自己的原创内容，做到结构像、语句不像、字数时长对标（±5%）。

适用场景：抖音 / 视频号短视频脚本、小红书笔记、公众号长文、知乎回答，以及跨平台的改写与多版本备选。

## 集团订阅号与内部号

用户给出自有稿件，要求润色、配图、参照现有版式输出审阅 PDF，或按反馈续改时，按[集团订阅号稿件制作与审阅](references/internal-newsletter-workflow.md)执行。指定对标的任务继续遵循下文的爆款拆解、原创和长度规则。

## 核心铁律（任何一步都不得违反）

1. **原创底线**：绝不复制对标文案的任何句子或段落。只借鉴方法论（框架、技法、节奏），不照搬具体内容；故事本身与具体表述必须完全不同。
2. **长度纪律**：默认严格对标，总字数 / 开头 / 中间 / 结尾 / 预计时长误差均控制在 ±5% 以内；仅在用户明确要求调整时放宽。
3. **落脚点是可复用规律**：拆解的产物是「规律」，不是「这条视频讲了什么」的摘要。
4. **不臆造数据**：引用互动数据或结论需有来源，不确定就先向用户澄清。
5. **合规提醒**：发布前提醒用户人工审核内容合规性与版权。

## 五步法主流程

按顺序执行，除非某步已被用户提供的信息完整覆盖。

### 第一步 · 获取对标素材
用户提供链接时，尽量提取标题、描述、口播/字幕文案、BGM 信息、点赞评论等数据。提取失败或用户更方便时，引导用户手动提供（标题、描述、文案、BGM 描述、互动数据）——手动方式 100% 可靠，优先使用。素材越详细，拆解越精准。

### 第二步 · 深度拆解
从 6 个维度产出《爆款方法论拆解报告》：开头钩子、文案结构、表达风格、时长节奏、内容策略、爆款要素。每个维度都要落到「可复用的规律」上。

- 完整的 6 维度拆解项、钩子类型清单、吸引强度评分、时长分配规律 → 读 `references/deconstruction-framework.md`
- 拆解报告的可填空模板 → 复制 `assets/deconstruction-report.md`

### 第三步 · 澄清需求
创作前确认 5 件事：核心内容、目标用户群体、要传递的价值或情感、是否已有初稿或关键词、风格偏好或限制。已有明确信息的不要重复问，只问缺口。

### 第四步 · 原创创作
用对标的结构逻辑与节奏重新填充用户自己的内容，产出 2-3 版不同风格备选。

- 创作铁律、每版输出格式、对标参数对比表、原创性声明、设计思路、亮点标注、拍摄建议 → 读 `references/creation-and-output.md`
- 交付文案的完整模板 → 复制 `assets/copy-deliverable.md`
- 各平台调性差异与格式 → 读 `references/platform-playbook.md`
- 核对字数/时长是否达标 → 运行 `scripts/length_check.py`（见下）

### 第五步 · 迭代优化
根据用户反馈多轮调整：优化开头钩子、调整结构节奏、改进表达风格。每次迭代保持对标参数同步更新。

## 快捷命令

| 命令 | 执行动作 |
|------|----------|
| `拆解 [链接或文案]` | 输出该作品的《爆款方法论拆解报告》 |
| `仿写 [对标素材] + [我的主题]` | 学方法论，产出原创文案 |
| `给我 3 版 [平台] 文案` | 产出多版本备选 |
| `把这篇长文改成小红书笔记` | 跨平台改写 |
| `帮我想 10 个开头钩子` | 批量生成钩子备选 |

## 长度校验脚本用法

对标参数核对交给脚本，避免手工估算偏差：

```bash
# 统计文案各段字数并估算时长（按中文口播约 4 字/秒）
python scripts/length_check.py --file copy.txt

# 与对标参数逐项比对，输出 deviation 与是否达标
python scripts/length_check.py --file copy.txt --benchmark '{"total":300,"hook":45,"body":210,"end":45,"duration":75}'

# 自定义口播语速（字/秒）
python scripts/length_check.py --file copy.txt --rate 4.5 --benchmark '{"total":300,"duration":75}'
```

文案文件用标记分段：`[开头钩子]`、`[中间内容]`、`[结尾总结]`，未标记的内容计入总字数。脚本按中文字符计数（标点不计），输出每段字数、占比、估算时长及相对对标的偏差，标出超出 ±5% 的项。
