# 原创创作与交付规范

## 创作四原则（不可违反）

1. **结构学习**：借鉴框架的槽位与节奏安排，用新内容重新填充。**禁止复制**对标文案的具体文字。
2. **风格学习**：模仿语言风格、句式特征、修辞手法。**禁止复制**具体句子或段落。
3. **内容原创**：所有文字 100% 原创。故事结构可参考，但故事本身与具体表述必须完全不同。
4. **长度对标**：总字数、开头、中间、结尾、预计时长误差均控制在 ±5% 以内；用户明确要求调整时除外。

## 每版文案的标准输出格式

```
[开头钩子：约X字，预计X秒]
正文……

[中间内容：约X字，预计X秒]
正文……

[结尾总结：约X字，预计X秒]
正文……

总计：约X字，预计X秒
```

## 每版必须附带的 5 项

1. **对标参数对比表**：总字数 / 开头 / 中间 / 结尾 / 时长 / 结构类型 / 语言风格 / 句式特征，逐项列出「对标值 / 新文案值 / 偏差」，直观展示是否在 ±5% 内。

2. **原创性声明**：明确说明仅借鉴方法论、内容 100% 原创。示例措辞：「本文案仅借鉴对标作品的结构与节奏规律，全部文字为原创，未复制任何原句。」

3. **设计思路说明**：钩子类型、结构、风格、句式、长度控制各采用了什么思路，对应对标里的哪条规律。

4. **亮点标注**：用标记明确标出钩子句、金句、转折点分别在何处。

5. **拍摄 / 表现建议**：语速、情绪基调、画面配合，并给出对标参考值，方便落地执行。

## 字数与时长估算口径

- 中文字符计数（标点不计入），脚本按此口径。
- 口播语速默认约 4 字/秒，可在脚本用 `--rate` 调整：
  - 快节奏短视频：4.5-5 字/秒
  - 正常讲解：4 字/秒
  - 情感/慢速：3-3.5 字/秒
- 预计时长 = 字数 ÷ 语速，再按停顿与画面留白适当上浮。

## 多版本创作

默认产出 2-3 版不同风格备选，版本之间要有**真实差异**，而不是换个开头。可从以下维度拉开差异：

- 钩子类型不同（痛点型 / 悬念型 / 数字型）
- 结构不同（清单 / 故事 / 对比）
- 语气不同（犀利 / 温和 / 幽默）

每版都要独立满足长度对标和 5 项附带内容。

## 迭代优化

用户反馈通常针对三处，按反馈定位并只改相关部分：

| 反馈方向 | 调整对象 | 保持不动 |
|----------|----------|----------|
| 优化开头钩子 | 第一段（换钩子类型或手法） | 中间价值、结尾、总字数 |
| 调整结构节奏 | 段落顺序、时长分配 | 语言风格、核心信息 |
| 改进表达风格 | 句式、词汇、修辞 | 结构、字数、数据 |

每次迭代后重新跑长度校验，并同步更新对标参数对比表；多轮保留历史版本，不覆盖。
