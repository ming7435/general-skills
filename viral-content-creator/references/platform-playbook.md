# 平台调性适配手册

同一个内容内核，在不同平台要用不同的结构与表达。创作前先确认目标平台，按本手册调整。

## 平台调性总览

| 平台 | 调性要点 |
|------|----------|
| 抖音 / 视频号 | 强钩子、快节奏、口语化、情绪驱动，前 3 秒定生死 |
| 小红书 | 标题带悬念或利益点、真诚感、清单/测评体、Emoji 分区排版 |
| 公众号 | 深度逻辑、小标题分层、开头设悬念、结尾金句收束 |
| 知乎 | 专业感、论证充分、案例支撑、结论前置 |

## 抖音 / 视频号

- **结构**：3 秒钩子 → 9-20 秒快节奏价值输出 → 3-6 秒收束/行动号召
- **表达**：短句为主、口语化、情绪强，多用第二人称「你」
- **字幕**：口播文案即字幕，一句一行，关键词放大
- **钩子**：前 3 秒必须出现冲突、利益或悬念，禁止铺垫
- **节奏**：平均每 1-2 秒一个信息点或画面切换
- **结尾**：引导互动（评论/关注）或一句金句

## 小红书

- **标题**：带悬念或利益点，可用数字、 emoji；两种常见范式
  - 悬念型：「没想到 XX 竟然可以这么…」
  - 利益型：「3 个动作，让 XX 直接翻倍」
- **正文**：真诚感第一人称，清单体或测评体，分点用 Emoji 分区
- **排版**：短段落、多换行、 emoji 作小标题，避免大段文字
- **标签**：结尾带相关话题标签，提升分发
- **配图建议**：封面图 + 分点配图，封面文字与主标题呼应
- **合规**：避免绝对化用语与未经证实的功效宣称

## 公众号

- **结构**：悬念开头 → 小标题分层展开 → 案例/论证 → 结尾金句 + 行动号召
- **表达**：允许长句与专业词，但要保持逻辑推进清晰
- **分段**：每 3-5 行一段，用小标题切分，防止阅读疲劳
- **深度**：给出信息增量（数据、案例、方法论），不堆情绪
- **配图建议**：顶部封面图 + 各节小标题配图

## 知乎

- **结构**：结论前置 → 分点论证 → 案例支撑 → 补充边界条件
- **表达**：专业、克制、少情绪词，多用「一方面/另一方面」等逻辑连接
- **论证**：每个观点配案例或数据，标注来源
- **收尾**：给可执行的建议，不喊口号

## 跨平台改写要点

把长文改成小红书笔记（或反向）时：

1. 保留核心信息点与数据，砍掉铺垫和论证过程
2. 按目标平台重排结构（长文→清单体，笔记→分层论述）
3. 重写标题与钩子适配平台调性
4. 重新分配 Emoji / 小标题 / 分段
5. 重新核对字数与时长（平台不同，对标参数可能不同）
