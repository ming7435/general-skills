# 爆款方法论拆解框架（6 维度）

拆解的唯一落脚点：**提炼可复用的规律，而不是总结这条视频讲了什么**。每完成一个维度，都要回答「这一条怎么迁移到别的内容上」。

## 维度一 · 开头钩子

拆出以下内容：

- **钩子类型**：悬念 / 痛点 / 共鸣 / 反转 / 利益 / 数字（可复合）
- **前 3 秒手法**：用了什么具体手法（提问、反常识断言、结果前置、身份点名、损失警告等）
- **原理**：为什么这个手法能抓住人（如：损失厌恶、信息差、自我相关、认知失调）
- **吸引强度**：按 1-10 分打分，并说明打分理由
- **可复用技巧**：抽象成一个可套用的句式或动作模板

### 钩子类型速查

| 类型 | 内核 | 典型手法 | 适用 |
|------|------|----------|------|
| 悬念 | 不说完，逼你往下看 | 「直到第三天，我才发现…」 | 故事型、过程型 |
| 痛点 | 戳中已经存在的问题 | 「你是不是也…」 | 知识型、解决方案型 |
| 共鸣 | 情绪/身份认同 | 「只有经历过的人才懂」 | 情感型、人群型 |
| 反转 | 打破预期 | 「我本以为…结果…」 | 剧情型、测评型 |
| 利益 | 直接给好处 | 「看完这条你能省下…」 | 干货型、清单型 |
| 数字 | 具体量化制造可信与紧迫 | 「3 个动作，10 分钟搞定」 | 清单型、教程型 |

## 维度二 · 文案结构

- **整体框架**：问题-解决方案 / 对比 / 故事 / 清单 / 递进（或组合）
- **各部分功能**：吸引注意 → 传递价值 → 促进行动，逐段标注它在干什么
- **时长占比**：开头 / 中间 / 结尾各占多少
- **转换节奏**：几秒一转、在哪里翻转、信息密度如何变化
- **可复用结构**：抽象成带槽位的骨架，如「钩子 → 3 个并列要点 → 一句行动号召」

## 维度三 · 表达风格

- **语言风格**：接地气 / 专业 / 幽默 / 严肃 / 温情
- **情感基调**：全片情绪曲线（平铺 / 递进 / 先抑后扬）
- **句式特征**：短句 / 长句 / 长短结合，是否口语化
- **词汇选择**：人称、口头禅、专业词密度、是否用方言
- **修辞手法**：押韵 / 排比 / 金句 / 对比 / 反问
- **可复用表达技巧**：提炼 2-3 个能直接迁移的句式或修辞套路

## 维度四 · 时长节奏

- **开头 / 中间 / 结尾各占多久**
- **整体节奏**：快 / 慢 / 快慢交替
- **转换频率**：平均每几秒一个镜头或话题切换
- **可复用时长分配规律**：如「15 秒视频：钩子 3s + 价值 9s + 收尾 3s」

### 常见时长分配参考

| 总时长 | 开头钩子 | 中间价值 | 结尾总结 |
|--------|----------|----------|----------|
| 15 秒 | 3 秒 | 9 秒 | 3 秒 |
| 30 秒 | 4 秒 | 20 秒 | 6 秒 |
| 60 秒 | 5 秒 | 45 秒 | 10 秒 |

## 维度五 · 内容策略

- **核心价值点**：这条内容到底给用户什么（信息 / 情绪 / 身份 / 谈资）
- **目标受众画像**：年龄、性别、兴趣、痛点、场景
- **击中的需求**：爽点 / 痛点 / 痒点，对应马斯洛或具体场景
- **差异化优势**：为什么是它火而不是同类内容火

## 维度六 · 爆款要素

- 按重要性排序，列出前 3-5 个真正的爆款驱动元素（不是罗列所有优点）
- 每个要素标注它属于哪个维度、为什么关键
- **需避免的坑**：这条内容或同类的翻车点、争议点、版权风险点

## 拆解报告自查清单

输出报告前逐条确认：

- [ ] 每个维度都写到了「可复用的规律 / 技巧」
- [ ] 钩子给出了类型、手法、原理、强度分、可复用句式
- [ ] 结构给出了框架、功能、时长占比、可复用骨架
- [ ] 时长分配三段加起来等于总时长
- [ ] 爆款要素做了排序（3-5 个），不是平铺
- [ ] 没有把对标原文当成自己的话复制进报告（引用需标明是原文）
