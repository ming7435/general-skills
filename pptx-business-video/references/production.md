# 制作与验收操作

下列命令从 Skill 根目录执行，路径替换为本次项目文件。三个脚本使用 Python 3 标准库。成片检查还需要 FFmpeg 和 ffprobe，可用 `--ffmpeg`、`--ffprobe` 指定可执行文件。HyperFrames、字体、配音能力从当前制作环境取得。

## 1. 提取原始素材

```sh
python scripts/extract_pptx.py "业务总结.pptx" "work/素材索引"
```

输出 `index.json` 和 `assets/`。按演示文稿列出的页序读取，隐藏页另作标记。每页的 `direct` 给出直接引用的包内路径，`assets` 字典映射到本地原始字节文件。版式与母版中的候选标识单列在 `layout_and_master_candidates`，须确认实际显示与颜色。索引同时收录图表 XML；原生图形的空间关系、图表单位、图片里的小字需要结合页面或原图复核。工具同时提取幻灯片原生表格中的文字，素材索引只列包内资源。输出使用新目录。

## 2. 用录好的旁白排时间

将下列结构保存为 `takes.json`。路径相对于该 JSON。每条 `wav` 指向已录制或合成的 PCM WAV。简短整句用 `text`；长段改用 `cues` 数组，每项给出 `start`、`end`（相对本段人声开头的实测秒数）和 `text`。这些时间来自听读或对齐结果。相邻同名章节会合并。

```json
[
  {"id":"opening","chapter":"业务问题","wav":"vo/opening.wav","text":"一条新需求交给谁处理？","pre_frames":6,"post_frames":8},
  {"id":"handoff","chapter":"需求分发","wav":"vo/handoff.wav","text":"评审通过后，按规则分发给责任团队。","post_frames":12}
]
```

```sh
python scripts/voice_timeline.py "takes.json" "work/时间轴" --fps 30
```

`timeline.json` 的镜头范围为左闭右开，`voice_frame` 是配音起点。`captions.srt` 和 `chapters.ffmeta` 使用同一时间基准。短片需要严格 30 秒并选择 30 fps 时加 `--target-frames 900`。余量分配给最后一个镜头；余量过长时调整片中留白。音长超过预算会报告缺多少帧，可据此精简文案或调整已有留白。

## 3. 渲染、反馈和复查

按本机 HyperFrames CLI 帮助确认预览、检查与渲染命令，在项目中保存实际用过的入口。镜头、字幕与音频采用同一时间轴，背景音乐单独混音。按目标交付规格导出；常用会议横版为 1920×1080、30 fps、H.264/AAC。打开最终 MP4 执行以下检查。

```sh
python scripts/check_export.py "成片.mp4" --srt "字幕.srt" --fps 30 --size 1920x1080
```

严格 30 秒短片可加 `--duration 30`。脚本逐帧解码并扫描接近全黑的画面，输出帧号和时间，以及编码、音轨时长、字幕边界与章节数。退出码 0 表示所做的技术检查通过；1 表示规格、字幕或解码异常；2 表示有近黑帧需要结合镜头意图查看。正常的黑场开头可以在人工检查中记录。意外黑帧优先检查前景与底图在切点的可见区间和小数秒舍入。用整数帧处理边界，确有需要可延长下层画面覆盖切点，再实际导出复查。

另做三项人工核对：从最终视频截取各章关键镜头，查看字号、品牌比例、字符与裁切；对照原页和字幕听数字、项目型号与计划用语；在旁白较轻的位置试听音乐平衡。单一音量峰值不能代表可懂度。检查导出工程中的素材引用和字幕同步，确认在解压目录内能重新打开或渲染。
